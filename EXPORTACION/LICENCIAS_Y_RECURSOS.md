No se ha consultado un registro externo para certificar derechos sobre las ilustraciones. Los originales de trabajo enviados al chat que no estaban en el árbol Git no se han reconstruido ni presentado como archivos del proyecto. Se conserva exactamente el material versionado, incluidas versiones responsive de WebP.

Las licencias y datos públicos de atribución de terceros se preservan porque forman parte de los avisos, no como datos privados de usuarios. Para una publicación pública en GitHub, revisar y documentar las condiciones de cada material; puede mantenerse el repositorio privado durante esa revisión.
